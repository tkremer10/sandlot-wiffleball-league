# Sandlot Wiffle Ball League website

## Preview locally
Open `index.html` in a browser. The site is responsive and uses plain HTML, CSS, and JavaScript; there are no build tools or dependencies.

## Publish online
Simple options:
1. Netlify Drop: sign in to Netlify and drag the unzipped `swl-website` folder into its manual deploy area.
2. GitHub Pages: create a repository, upload `index.html` (and this README if desired), then enable Pages in repository settings.
3. Any static host: upload `index.html` as the site entry point.

## Before launch
- Replace the text-based SWL marks with official team/league logos.
- Add team captains, rosters, official player statistics, and full regular-season schedules.
- Confirm historical title/award records and add any missing 2025/2026 details.
- If you want live-updating stats or admin editing, connect a database/CMS or a spreadsheet-backed data source; this prototype is static.
- Confirm sponsor terms, field address, league contact details, and privacy/registration policies before adding registration or payment features.

The current page intentionally labels unavailable records rather than inventing them.
